# Targeted research: a real paired medical-image prototype

Date: 2026-11-17. This is a targeted engineering source review, not an exhaustive systematic review or meta-analysis. Search sources were official GitHub repositories, original papers/author pages, the official Mendeley dataset, NeurIPS/Cambridge records and MONAI documentation. No secondary tutorial benchmark is treated as established model performance.

Question: Which established implementation can be adapted affordably to demonstrate real clinical images, paired metadata, baseline comparisons and working inference for an applied data-science portfolio?

Criteria: genuine public paired records; explicit data/code permissions; inspectable implementation; manageable local CPU inference/training; clear evidence boundaries. Prefer official authors' code over a high-scoring third-party notebook. Reject unpaired record fusion, hidden synthetic metadata, copied performance numbers and unclear code reuse permission.

| Candidate | Verified basis | Practical assessment |
|---|---|---|
| PAD-UFES-20 + author's MetaBlock | Original data: 2,298 clinical smartphone images, 1,373 patients, 1,641 lesions, image/patient/lesion keys; CC BY 4.0. Official MetaBlock repository MIT; 16 stars when checked. | Direct image + metadata pairing, small reusable component. Selected as a documented fusion comparator. |
| HEALNet | NeurIPS 2024 author repository; Apache-2.0, 121 stars when checked. Cross-modal attention with spatial encodings and shared latents. | Selected as an advanced architecture adaptation; original TCGA whole-slide/omics experiment is much larger and is not reproduced here. Upstream code needs explicit fail-closed behavior rather than its broad swallowed exception. |
| MONAI tutorials | Official medical-imaging framework/tutorials, Apache-2.0; 2,586 stars when checked. Includes deployment examples. | Useful deployment reference. The surfaced image/tabular early-fusion tutorial uses synthetic data, so it does not satisfy this user's real-data requirement by itself. No claim of MONAI use unless actually added to implementation. |
| PRISM | Official author repository and linked paper, paired skin-image/metadata design. No repository license detected; 0 stars at check time. | Read for design comparison, do not copy code without a reuse license. Its partially private extended cohort is not used. |
| MedMNIST | Official lightweight real biomedical-image benchmarks. | Good image-only exercise, but does not supply the needed paired clinical table for this task. Do not invent clinical metadata to make it multimodal. |

Planned contribution: a reproducible CPU experiment, defensible group/label boundaries, an understandable bilingual viewer, and a deployed research inference demonstration. It cannot establish hospital integration, clinical efficacy, raw genomic expertise or CT/MRI experience. The existing METABRIC expression project remains a separate cohort; the two datasets are never matched to each other.

Preferred low-cost presentation: static public web assets with actual browser inference if export parity succeeds, plus a local/containerized Python inference API. This avoids creating an always-on VM. Hosted research inference is distinct from hospital clinical deployment.
